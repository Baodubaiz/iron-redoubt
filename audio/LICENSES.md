# Audio Asset Licenses

All audio in this folder is **original**. It was synthesized procedurally by
`tools/audio_gen/gen_audio.gd`, which uses sine, triangle, soft-square and soft-saw oscillators, FM synthesis, filtered noise and
envelopes. No third-party samples, loops or presets are used.

| Files | Source | License |
|---|---|---|
| `sfx/*.wav` (20 files, Reforged sci-fi set) | Generated by `tools/audio_gen/gen_audio.gd` | Owned by the project; free to redistribute with the game |
| `music/ambient_loop.wav` | Generated by `tools/audio_gen/gen_audio.gd` (A minor–F–C–G pad + pluck arpeggio, 32 s seamless loop) | Owned by the project; free to redistribute with the game |

To regenerate the files deterministically (fixed seed), run:

```bash
godot --headless --path . -s res://tools/audio_gen/gen_audio.gd
```

Then re-import with `--import`.

Other assets (fonts, icons, sprites): see `docs/ASSET_SOURCES.md`.
